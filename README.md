# Wild-Mushroom-
مشروع متخصص في زراعة وإنتاج المشروم المحاري عالي الجودة، لا يقتصر المشروع على إنتاج المشروم الطازج فقط، بل يتم تقديمه أيضًا في صورة منتجات غذائية مطبوخة وجاهزة للبيع والاستهلاك،  ويهدف المشروع إلى تقديم منتجات غذائية طبيعية، آمنة وعالية الجودة، مع الحفاظ على جودة المشروم في كل مراحل الإنتاج والتجهيز والتوزيع.
